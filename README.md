# Hu3 Pet

O Hu3 Pet agora tem um cliente de jogo em Godot 4.7.2.

- godot/ contém o projeto do jogo.
- O cliente é exportado para Web durante o build Docker.
- O Next.js continua responsável pelas APIs, banco, admin e sistemas de progressão.
- A primeira fatia jogável é um quarto 3D cozy com pet, câmera ortográfica e objetos interativos.

O objetivo é evoluir o cliente sem reescrever o backend existente.
